# WanderLog API

REST API para gestionar diarios de viaje. Los usuarios pueden crear itinerarios,
añadir destinos y actividades, y descubrir viajes  de otros viajeros.

## Stack tecnológico

- Java 24
- Spring Boot 3
- PostgreSQL
- Maven
- Docker
- JWT (autenticación)

## Funcionalidades previstas

- Registro y login con JWT
- CRUD de viajes (públicos y privados)
- Gestión de destinos y actividades por viaje
- Valoraciones de viajes públicos
- Filtros por país y tipo de actividad
